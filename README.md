# HTML Tools

A growing collection of **single-file HTML tools** (each tool lives in its own subdirectory).

## Tools

- **TMDB watchlist**: search movies/TV and save a local watchlist — `tmdb-watchlist/`

## Running locally

Any static file server works. For example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/` and click a tool.
